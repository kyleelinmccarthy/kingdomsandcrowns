# Blind rune pass — rune-g23 (band g23)

<!-- rune-blind-pass sheet v1 · pool: rune-g23 · entries: 80 -->

**Do not open `src/content/runes/rune-g23.json`** — not before you start, not to
check yourself partway. This sheet is worth exactly as much as that rule is kept.

Each line below is one rune stone. A child sees a picture of the thing that needs the rune, reads
the shown line, and builds a word by tapping tiles in order. Each tile is used at most once, and
not every tile is needed: some are decoys. The tiles are listed A-Z here; the child sees them
shuffled. Answer each line ON ITS OWN: the lines are shuffled and unrelated.

This is a **dictation** pool: the child HEARS the word (the `Heard:` line is spoken to them), so
you are told it too. For each line, check two things:

- the heard word can be built from the tiles, each tile once;
- the shown line fits the picture (it is about the thing that needs the rune).

If both hold, write the heard word after `Answer:`. If either fails, write `?`.
This pass cannot test whether another word would also fit, because the word is told: that is
the dictation's design.

Leave the `#` codes alone. They pin each answer to the line you actually read, so that if an entry
is edited afterwards the stale answer is reported rather than trusted.
