# Blind sort pass — sort-science-g68 (grade 6)

<!-- sort-blind-pass sheet v1 · pool: sort-science-g68 · sets: 4 -->

**Do not open `src/content/sorts/sort-science-g68.json`** — not before you start, not to
check yourself partway. This sheet is worth exactly as much as that rule is kept.

Each set below is one sorting job: two bins, numbered 0 and 1, and a list of things to
sort. Answer as a careful reader at the grade above would. After `Answer:` on each line
write one of:

- `0` or `1` — the bin the thing belongs in.
- `both` — a reasonable person could defend either bin. This is as much a defect as a
  wrong key, and it is the one a reader skips past when they are only hunting for
  mistakes, so use it whenever it is true.
- `?` — it does not belong in either bin, or you cannot place it from what is in front of you.

Leave the `#` codes alone. They pin each answer to the thing you actually read, so that if
an item is edited afterwards the stale answer is reported rather than trusted.
