# Blind rune pass — rune-g45 (band g45)

<!-- rune-blind-pass sheet v1 · pool: rune-g45 · entries: 80 -->

**Do not open `src/content/runes/rune-g45.json`** — not before you start, not to
check yourself partway. This sheet is worth exactly as much as that rule is kept.

Each line below is one rune stone. A child sees a picture of the thing that needs the rune, reads
the shown line, and builds a word by tapping tiles in order. Each tile is used at most once, and
not every tile is needed: some are decoys. The tiles are listed A-Z here; the child sees them
shuffled. Answer each line ON ITS OWN: the lines are shuffled and unrelated.

The child is given a meaning, not the word. Build the word the shown line (and the `Heard:` line,
where there is one) asks for, from the tiles alone. After `Answer:` on each line write one of:

- one word — the word you would build.
- `both` and then every word that fits the line AND can be built from the tiles — when more than
  one does. This is as much a defect as a wrong key, and it is the one a reader skips past when
  they are only hunting for mistakes, so use it whenever it is true.
- `?` — no word fits, or you cannot tell from the line and the tiles.

Leave the `#` codes alone. They pin each answer to the line you actually read, so that if an entry
is edited afterwards the stale answer is reported rather than trusted.
